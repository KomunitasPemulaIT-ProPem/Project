# Project

Repository kolaborasi untuk belajar dan mengembangkan project IT
bersama komunitas Komunitas Pemula IT.

## Cara Berkontribusi

1. Fork repository ini
2. Buat branch baru
3. Kerjakan kontribusi
4. Commit perubahan
5. Buat Pull Request

Semua orang boleh berkontribusi!

- Dokumentasi
- Bug fixing
